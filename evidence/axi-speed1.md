# AXI speed and recovery evidence

Field-test baseline (2026-09-26; see firstmate's `ops-vast-sshkey1/report.md`): 136 calls over 33 min; ~25 AXI actions, 79 separate SSH round trips, 20 setup/build calls. Tool execution totaled 5.6 min; ~80% of elapsed time was agent deliberation. Individual Mac actions took 0.75–4.22 s; full OCR ~1.3–1.4 s. A replayd `SCStreamErrorDomain -3821` left frame 49 stale until the session stopped.

Current candidate, private 1280×720 task-owned Xvfb: `npm test` 31/31, `cargo test` 43/43, `packages/axi/test/flow.mjs` passed; the flow verifies owner PID and X server identity and reaps all task processes. Three synthetic steps (`press`, `type`, 10 ms `wait`) took 176 ms across separate CLI calls versus 80 ms in a single batch on one run; see `axi-speed1-xvfb.json` (not a like-for-like Mac baseline).

Signed Mac dev app (`dev.desklink.host`), actual AXI bridge: simulated `SCStreamErrorDomain -3821` surfaced as `session.capture.stopped`; while stopped `look` returned `stream-stopped` instead of pixels; bounded reopen then resumed `streaming`, with frame sequence advancing from 23 to 24 and beyond. This proves the simulated stop/recovery, not the cause of replayd's original stop. The `axi-record` signed-app path recorded 30 screenshots while AXI applied 12 `press Shift` events; `agent-cursor-redacted.mp4` shows the blue cursor and changing halo. Its 100×100 crop is redacted outside the cursor strip; `agent-cursor-redacted.png` is one frame. The AXI capture intentionally excludes the overlay; these screenshots use an independent ScreenCaptureKit capture path.

One persistent SSH Unix-socket forward from Linux to that Mac carried five repeats of `press Shift`, `press Shift`, `wait 10`: median separate 320 ms vs batch 112 ms (2.86× faster, 3 CLI calls to 1); see `axi-speed1-mac.json`. This eliminates 2 of 3 per-action SSH logins in the tested sequence; it does not reduce agent deliberation time. Actions now acknowledge input immediately; frame waiting is opt-in and frame timeout after applied input is a successful result.

After validation the bridge, engine, overlay, recorder and SSH tunnel exited. The original app binary was restored and re-signed; `codesign --verify --deep --strict` succeeded, and `restored-capabilities.json` records both capture and input grants as `granted`. No Mac windows were opened or closed by AXI actions. OCR was unavailable on that Mac, so targeted OCR/ref behavior was exercised by private Xvfb and TypeScript tests, not on macOS.
